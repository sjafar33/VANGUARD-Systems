# AI use disclosure

- The Swift source code, tests, procedural artwork code and documentation in this repository were written with substantial help from Anthropic's Claude (Claude Code), working from a design brief written by the team. Team members reviewed, built, ran and tested the result.
- The NASA reference values were retrieved from the official sources and transcribed into `science_package.json` during an AI-assisted session. The values, locators and verification method are recorded in that file and in `SCIENCE_AND_DATA.md`.
- All in-game artwork is drawn procedurally by code at run time (Core Graphics and SpriteKit). No AI image, video or audio generators were used, and no NASA logos or insignia are reproduced.
- The background music and sound effects are synthesized at run time by code in this repository (`LofiComposer.swift`, `SoundFX.swift`) from sine waves and noise. The composer code was written with AI assistance; no samples, recordings, or third-party music were used, so the music is original to this project and covered by the project license.
- The game itself contains no AI features and makes no network calls.
