# AI use disclosure

- AI coding tools (Claude Code and Codex) assisted the Swift implementation, tests, debugging, procedural artwork code, documentation and caption wording, working from the team's design brief. The resulting application was built and tested; see VALIDATION.md for the scope and limits of verification.
- NASA reference values were retrieved from official sources and transcribed during AI-assisted development. Values, source locators and verification methods are recorded in science_package.json and SCIENCE_AND_DATA.md. Archived event timestamps were independently checked against the official CCMC table; no human classroom study is claimed.
- All in-game artwork is drawn procedurally by code at runtime (Core Graphics and SpriteKit). No AI image, video, or audio generator supplied game assets. NASA logos or insignia are not reproduced.
- Background music and sound effects are synthesized by project code from sine waves and noise. The composer code was AI-assisted; there are no third-party samples or recordings.
- The final 27-second demonstration is actual gameplay recorded by the project owner on an iPad Air and edited by the owner in DaVinci Resolve. It is not AI-generated video. Watch it on [YouTube](https://youtube.com/shorts/OFn2BLQ81js).
- The game itself contains no runtime AI feature and makes no network calls.
- This disclosure describes tool use; assistant identities are not commit authors, co-authors or GitHub collaborators.
